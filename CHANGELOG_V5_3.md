# Changelog SIMBERPAS V5.3

## Perubahan utama

- Mengubah arsitektur akses menjadi internal pusat.
- Menetapkan empat peran profesional: Administrator Utama Sistem, Analis Pemberitaan Strategis, Operator Akuisisi Data Berita, dan Pimpinan Eksekutif.
- Menghapus pembatasan akses akun berdasarkan Kanwil/UPT.
- Menyederhanakan workflow menjadi Belum Ditelaah, Perlu Koreksi, Terverifikasi, Tidak Valid, dan Diarsipkan.
- Menambahkan menu Pusat Telaah.
- Menambahkan menu Warning News.
- Peringatan Tinggi/Kritis muncul sebelum verifikasi sebagai Peringatan Awal.
- Peringatan terverifikasi dibedakan dari hasil deteksi awal.
- Menambahkan tanda seru merah tua pada marker abu-abu untuk warning awal yang belum ditelaah.
- Memisahkan kemampuan input dan kemampuan analisis.
- Operator Akuisisi tidak dapat mengubah sentimen, kategori, urgensi, atau keputusan verifikasi.
- Pimpinan Eksekutif memperoleh akses baca-saja ke dashboard, warning, peta, AI, data terverifikasi, dan laporan.
- Mempertahankan input manual dan menunda sinkronisasi Google Spreadsheet.
- Menambahkan migrasi otomatis peran dan status lama.
